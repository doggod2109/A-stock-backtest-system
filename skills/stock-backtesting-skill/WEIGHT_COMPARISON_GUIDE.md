# 权重对比结果呈现方式

## 📊 多种呈现方式

权重对比工具提供 **4种** 不同形式的输出，方便你直观理解不同权重的效果。

---

```
平衡配置      32.10%      47.30%      1.03      -12.30%   68.18%
量能优先      28.90%      42.60%      0.98      -14.80%   66.67%
MACD优先      25.40%      37.50%      0.88      -16.50%   63.64%
```

**使用场景：**
- 需要精确数值时
- 对比多个组合时
- 导出到Excel时

## 4️⃣ 文件导出

**特点：** 保存详细结果，支持后续分析

### 生成的文件
```
weight_comparison_000592_20260311_113104/
├── weight_comparison.xlsx    # Excel对比表
├── weight_comparison.json    # 详细JSON数据
└── recommended_weights.txt   # 推荐配置（可直接复制）
```

#### Excel 文件内容
- **详细数据表**: 包含所有指标数值
- **对比表格**: 格式化的百分比显示

#### JSON 文件内容
- 完整的回测数据
- 可用于程序化分析

#### 推荐配置文件
```python
WEIGHTS = {
    'trend': 35,  # 35%
    'bias': 25,  # 25%
    'volume': 10,  # 10%
    'support': 10,  # 10%
    'macd': 10,  # 10%
    'rsi': 10,  # 10%
}
```

**使用场景：**
- 归档保存
- 分享给他人
- 后续分析

## 🚀 使用方法

### 快速对比

```bash
cd skills/stock-backtesting-skill
python3 backtesting/weight_comparison.py
```

### 修改待测试的权重组合

编辑 `weight_comparison.py`，修改 `WEIGHT_SETS`：

```python
WEIGHT_SETS = [
    {
        'name': '我的配置1',
        'weights': {'trend': 30, 'bias': 30, 'volume': 10, 'support': 10, 'macd': 10, 'rsi': 10}
    },
    {
        'name': '我的配置2',
        'weights': {'trend': 40, 'bias': 20, 'volume': 15, 'support': 5, 'macd': 10, 'rsi': 10}
    },
    # 添加更多组合...
]
```

### 自动权重优化（穷举所有组合）

```bash
python3 backtesting/compare_weights.py
```

这会测试所有可能的权重组合（~129组），找到最优解。

## 📊 对比指标说明

| 指标 | 说明 | 越高越好？ |
|------|------|-----------|
| 总收益率 | 整体盈利水平 | ✅ |
| 年化收益率 | 年化盈利能力 | ✅ |
| 夏普比率 | 风险调整后收益 | ✅ |
| 最大回撤 | 最大亏损幅度 | ❌ |
| 胜率 | 盈利交易占比 | ✅ |
| 平均盈亏 | 每笔交易平均收益 | ✅ |
| 交易次数 | 总交易笔数 | - |

---

## 💡 选择建议

### 追求高收益
关注：**总收益率、年化收益率**
- 适合：激进型投资者
- 风险：较高回撤

### 追求稳健
关注：**夏普比率、最大回撤、胜率**
- 适合：稳健型投资者
- 风险：收益可能较低

### 综合考虑
推荐使用 **夏普比率** 作为主要指标
- 平衡收益与风险
- 量化策略的黄金标准

## 🎯 示例解读

假设对比结果：

```
当前默认:  收益45% | 夏普3.26 | 回撤-7.46%
趋势优先:  收益57% | 夏普1.37 | 回撤-15.20%
```

**分析：**
- 趋势优先收益更高（57% vs 45%）
- 但夏普比率更低（1.37 vs 3.26）
- 最大回撤更大（-15% vs -7%）

**结论：**
- 当前默认策略更稳健
- 趋势优先策略风险较高

权重对比提供 **4种呈现方式**：

4. **文件** - 详细数据导出

**根据需求选择合适的方式！** 🎨
